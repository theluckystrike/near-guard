What the contract does

owner sets a policy per agent:  per_tx cap, daily cap, receiver allowlist
agent calls spend(receiver, amount) with the amount attached
contract checks the policy -> pays, or panics before any state changes
every write emits a NEP-297 EVENT_JSON line
a function-call access key lets the agent call only this contract, only spend()
Chain: NEAR testnet. Contract: zouguard-11141131.testnet. Source: github.com/theluckystrike/near-guard.
